포지션 상세
카카오헬스케어 AI팀은 AI-native EMR을 만드는 '프로젝트 X' 직속 조직입니다. 기존 EMR의 사용 경험을 AI Agent 중심으로 다시 설계하고, 의료 현장에 실제로 쓰이는 제품을 만드는 것을 목표로 합니다. AI팀은 전체 Agent Architecture 설계부터 기능 단위 Agent 개발까지 AI Agent 영역 전반을 담당하며, LLM, RAG, Multi-Agent 등 빠르게 진화하는 기술을 의료 도메인에 적용해 연구 단계의 아이디어를 실제 제품으로 옮기는 일을 합니다. 제품팀, 의료 도메인 전문가, 데이터팀과 긴밀하게 협업하며 기술 의사결정을 함께 만들어 갑니다.
주요업무
• 의료 데이터를 활용해 AI/ML 기반 기능을 설계하고, 실제 서비스에 탑재할 수 있는 형태로 개발
• LLM 기반 AI Agent와 Multi-Agent 시스템 구조 설계, 각 Agent가 유기적으로 협력하도록 구현
• 의료 정보 검색의 정확도를 끌어올리는 RAG 검색·추론 파이프라인 구축 및 고도화
• LangChain, LangGraph, ADK 등 Agentic AI 프레임워크 기반의 Tool Calling, Sub-Agent, Workflow Orchestration 개발
• LLM·Agent 실행 과정의 추적·로깅, 문제 구간 분석을 통한 안정성과 품질 개선
• 프롬프트 개선, 평가 체계 구축, 결과 분석을 통한 LLM 서비스 품질 고도화
