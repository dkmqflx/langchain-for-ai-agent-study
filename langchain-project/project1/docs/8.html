8

파라미터 튜닝 & 실험 정리 (선택)

선택 · 심화 ⏱ 반나절
🎯 목표

지금까지의 실험을 정리하고, 몇 개 파라미터를 바꿔 최적 설정을 근거와 함께 고른다.

🛠 할 일
  • chunk_size(500 / 1000 / 1500), top-k(3 / 4 / 6), rerank top_n, hybrid weights를 바꿔가며 evaluate.py rerank로 점수를 남긴다. (CSV가 덮어써지지 않게 실행마다 파일명을 바꿔 보관)
  • 결과를 하나의 표로 모아 "어떤 설정이 왜 최선인지" 한 문단으로 정리한다.
  • 바꾼 설정마다 git commit — 커밋 히스토리가 곧 실험 로그가 된다.
✅ 검증 게이트 3가지 이상 설정의 지표를 한 표에 모으고, 최종 설정을 숫자 근거로 선택한 문장이 있으면 통과.
🎓 배우는 것

실험 관리와 의사결정 — "감이 아니라 지표로 정했다"는 이력서/면접 서사.
