02. Agent 기초 — Tool · Memory · Middleware

학습 로드맵 · 8개 강의  ·  원문: docs/02.agent-basic.md  ·  난이도: 🟢 입문

에이전트를 이루는 기본 재료를 배웁니다 — 도구(Tool)로 능력을 주고, 기억(Memory)으로 대화를 잇고, 미들웨어(Middleware)로 실행 흐름을 통제하고, 구조화 출력으로 결과를 정돈합니다.

📖 사용법 각 항목을 클릭하면 해당 강의 교재(HTML)로 이동합니다. 실습 노트북(.ipynb)을 열기 전에 같은 번호의 교재를 먼저 읽어보세요.

강의 목록

01
Tool 기초1장 Tool

@tool로 도구를 만들어 create_agent에 장착하는 법.

02
Tool 심화: 외부 API 호출 도구1장 Tool

requests로 실제 웹 API를 호출하는 도구 만들기.

03
Memory 기초 (Short-term)2장 Memory

InMemorySaver·thread_id로 대화별 단기 기억 유지.

04
Tool Emulator1장 Tool

실제 도구 없이 LLM으로 도구 결과를 모킹(가짜 실행).

05
Middleware: TodoList3장 Middleware

write_todos로 복잡한 작업의 할 일을 자동 관리.

06
Middleware: Human-in-the-Loop3장 Middleware

민감한 도구(이메일 전송 등) 실행을 사람이 승인·거부.

07
Middleware: PII 개인정보 탐지3장 Middleware

이메일·카드번호 등 개인정보를 탐지·마스킹.

08
Structured Output4장 Structured

에이전트가 구조화된(정해진 형식) 답변을 생성.
