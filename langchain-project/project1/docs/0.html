프로젝트 셋업 & 준비물

신규(환경) ⏱ 30분
🎯 목표

독립 실행되는 프로젝트 폴더와 가상환경, 필요한 키를 준비해 "빈 캔버스"를 만든다.

🧠 개념

학습은 노트북에서 했지만, 서비스는 재실행 가능한 스크립트/모듈이어야 합니다. 그래서 노트북이 아니라 .py 파일로 구조를 잡습니다.

🛠 할 일

1) langchain-project 안에 작업 폴더를 만들고 uv로 환경을 초기화합니다. (학습 때 쓴 uv 그대로)

터미널
cd ~/Documents/langchain-study/langchain-project
mkdir p1-rag-service && cd p1-rag-service

uv init .
uv add langchain langchain-openai langchain-chroma langchain-community \
       langchain-text-splitters langchain-classic pymupdf python-dotenv
# 하이브리드·리랭커 (STEP 3~4)
uv add rank-bm25 sentence-transformers
# 서빙·관측·평가 (STEP 5~7에서 사용)
uv add fastapi "uvicorn[standard]" langfuse ragas datasets pandas

2) 폴더 구조를 아래처럼 잡아 둡니다(파일은 STEP마다 채웁니다).

p1-rag-service/
├── data/                # 여기에 PDF를 넣습니다 (3~10개)
├── cache/               # 임베딩 캐시 (자동 생성)
├── chroma_db/           # 벡터DB 저장소 (자동 생성)
├── ingest.py            # STEP 1
├── rag.py               # STEP 2, 3, 4, 6
├── main.py              # STEP 5
├── eval_data.json       # STEP 7 (골든셋)
├── evaluate.py          # STEP 7
├── .env
└── README.md            # STEP 9

3) .env를 만듭니다. (OpenAI 키는 학습 때 쓰던 것 재사용, Langfuse는 STEP 6에서 발급)

.env
OPENAI_API_KEY=sk-...
# STEP 6에서 채웁니다
LANGFUSE_PUBLIC_KEY=
LANGFUSE_SECRET_KEY=
LANGFUSE_HOST=https://cloud.langfuse.com

4) data/에 PDF 몇 개를 넣습니다(도메인 선택 참고).

✅ 검증 게이트 uv run python -c "import langchain, fastapi, langfuse, ragas; print('ok')" 가 ok를 출력하고, data/에 PDF가 1개 이상 있으면 통과.
🎓 배우는 것

노트북 → 재현 가능한 프로젝트로의 전환. 의존성·환경·비밀키 관리(모든 실무 프로젝트의 0단계).
